# YouTube Media Transcript

Use this skill when the user gives a YouTube link and wants a repeatable workflow that:

- downloads `mp4` and `mp3`
- runs Whisper transcription to produce English `srt`
- translates the transcript into Chinese `srt`
- stores outputs in a dated, per-video folder

## Workflow

This installed skill is linked to:

`__REPO_ROOT__`

Run:

```bash
cd __REPO_ROOT__
./tools/run_youtube_media_subtitle_pipeline.sh "<youtube-url>"
```

Optional arguments:

```bash
cd __REPO_ROOT__
./tools/run_youtube_media_subtitle_pipeline.sh "<youtube-url>" 2026-04-12 chrome
```

## Output Layout

The script stores each video in:

`downloads/youtube/YYYY-MM-DD/<video-slug>/`

Inside each item folder:

- `video/`: MP4
- `audio/`: MP3
- `transcripts/`: `*.en.srt` and `*.zh.srt`
- `logs/`: yt-dlp, Whisper, translation, and polish logs
- `manifest.txt`: URL, title, timestamps, and output paths

## Notes

- The workflow assumes Chrome cookies by default because some YouTube links require login state.
- English subtitles come from local Whisper transcription.
- Chinese subtitles are generated by local machine translation and then lightly polished, so they are usable but not fully human-edited.
- If the user only provides a link, proceed with the default date folder and Chrome cookies unless they ask otherwise.
